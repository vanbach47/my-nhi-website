# Personal Website (starter)

## Cách xem nhanh
- Mở file `index.html` bằng trình duyệt.

## Cách deploy đơn giản
- GitHub Pages (static): push repo lên GitHub → Settings → Pages → chọn branch.
- Hoặc Netlify/Vercel: kéo-thả thư mục.

## Việc cần anh cung cấp để Neo điền nội dung
- Tên hiển thị, 1 câu định vị (headline)
- 3 kỹ năng/điểm mạnh
- 3–6 dự án (tên + mô tả ngắn + link)
- Email/phone + các link social
- Ảnh avatar/logo (tuỳ chọn)
